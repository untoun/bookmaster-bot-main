**BookMaster Bot** — Telegram-бот для онлайн-записи на услуги. Подходит для салонов красоты, барбершопов, консультантов и любого сервисного бизнеса. Включает систему отзывов, программу лояльности, напоминания, аналитику и CSV-экспорт.

---

## Возможности

| Функция | Описание |
|---------|----------|
| **Многошаговая запись** | Услуга -> Мастер -> Дата -> Время -> Подтверждение |
| **Автослоты** | Свободные слоты рассчитываются из расписания мастера и длительности услуги |
| **Мои записи** | Просмотр всех записей, отмена предстоящих |
| **Повторная запись** | Кнопка «Повторить запись» для завершённых бронирований — предзаполняет услугу и мастера |
| **Поиск услуг** | Поиск по названию (частичное совпадение, регистронезависимый) |
| **Отзывы и рейтинг** | Оценка 1-5 звёзд + комментарий после завершения записи; средний рейтинг мастера |
| **Профиль мастера** | Все отзывы, средний рейтинг, статистика |
| **Программа лояльности** | Каждый 5-й визит — скидка 20%; отображение статуса в профиле |
| **Профиль клиента** | `/profile` — статистика, лояльность, предстоящие записи, любимый мастер |
| **Напоминания** | Автоматические за 24ч и за 2ч до записи (APScheduler) |
| **Выходные мастеров** | Админ задаёт конкретные даты, которые исключаются из доступных |
| **Заметки о клиентах** | Админ может добавлять заметки (аллергии, VIP и т.д.) |
| **CSV экспорт** | Экспорт записей за период и расписания мастеров в CSV-файл |
| **Аналитика** | `/stats` — записи за месяц, выручка, топ услуг, загрузка по дням, рейтинг мастеров |
| **Кулдаун** | 1 запись на услугу в день на пользователя |
| **Уведомления** | Администратор получает уведомление о новой записи |
| **Админ-панель** | Управление услугами, мастерами, расписанием, статусами, выходными, заметками |
| **FSM** | Конечный автомат для всех пошаговых сценариев |
| **Async** | Полностью асинхронный код на aiogram 3 + aiosqlite |

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-repo/bookmaster-bot.git
cd bookmaster-bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env: указать BOT_TOKEN и ADMIN_ID

# 4. Запустить бота
python bot.py
```

## Программа лояльности

- Каждый завершённый визит учитывается
- Каждый 5-й визит дарит скидку 20%
- Скидка отображается при подтверждении записи
- Настройки: `LOYALTY_EVERY_N` и `LOYALTY_DISCOUNT_PERCENT` в `config.py`

---

## Напоминания

Бот автоматически отправляет напоминания:
- **За 24 часа** до записи
- **За 2 часа** до записи

Используется APScheduler с интервалом проверки 30 минут.
